# clickherecork.com

The site of ClickHere Cork, an internet café.

## Contents

- PHP pages with login, polls, posts, a mailer and a chat.
- A machine monitor and online user list.
- A phpBB2 forum, phpMyAdmin and the FCKeditor rich text editor.
- AdSense blocks and Google helpers.

## Tech

- PHP and MySQL
- JavaScript

This is an archive of an old site, kept for reference.
